# Chronous playground (shadcn/ui)

A real shadcn/ui project that renders the registry component straight from
`registry/default/chronous-calendar/chronous-calendar.tsx`, so what you see here
is exactly what `npx shadcn add` installs.

```sh
npm run dev --workspace @midstem/chronous-playground-shadcn
```

Query parameters preset the calendar: `view`, `date`, `tz`, `locale`,
`events=none` and `theme=light|dark`.

# `@midstem/chronous-react`

Headless React primitives on top of [`@midstem/chronous`](../core): hooks, prop
getters and compound components. The library owns geometry and semantics,
cosmetics stay opt-in.

## Installation

```bash
npm install @midstem/chronous @midstem/chronous-react
```

`@midstem/chronous` is a peer dependency and is installed alongside.
